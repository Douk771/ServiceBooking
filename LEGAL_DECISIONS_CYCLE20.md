## 3. Вне кода — действия заказчика (команда готовит материалы)

1. Значения `legal.values.json` (ФИО, ИНН, адрес для корреспонденции, почта, телефон, ответственный,
   почта ответственного, НДС-оговорка) — заказчик заполняет **на боевой машине**, в git не кладётся.
   Срок ответа = 10 рабочих дней (решение выше).
2. Подать уведомления в РКН (ст. 22 и ст. 12) по текстам legal-counsel.
3. Договор с GREEN-API (нужен только для выпуска WhatsApp-канала, публикацию текстов не блокирует,
   если D1 не утверждает его наличия).
4. Подписать акты принятия рисков (Q-L11, C-13, CYCLE18 В1, В4) — готовит legal-counsel.
5. Ретроспективная проверка `revoke-preview` / `export` / `delete` по боевым логам
   (`INCIDENT_CHECK_PROCEDURE_CYCLE16.md`, TD16-3) — нужен доступ к бою.
6. Вычитка итогового комплекта живым юристом (C-5): legal-counsel готовит пакет «что читать
   в первую очередь» (сводный список из CYCLE16 §8, CYCLE18 §7, C17-10 и новых правок цикла 20).
