# Руководство пользователя EZBOOK

EZBOOK — сервис онлайн-записи. На одной платформе работает много независимых компаний: у каждой
своя страница, свои услуги, свои сотрудники и своё расписание.

Руководство разбито по ролям. Найдите свою — читать чужие разделы не нужно.

| Пришли записаться к мастеру | [Запись на услугу — для клиента](client.md) |
| Работаете мастером в салоне | [Кабинет мастера](master.md) |
| Владеете компанией на платформе | [Кабинет владельца компании](owner.md) |

## Роли в двух словах

- **Клиент** — записывается на услуги. Может делать это с аккаунтом или без него (как гость).
- **Мастер** — принимает клиентов: видит свои визиты, отмечает их выполненными, ведёт базу клиентов
  и своё расписание.
- **Владелец компании** — заводит компанию, услуги и сотрудников, настраивает расписание всей
  команды, смотрит отчёты и управляет настройками витрины.
- **Администратор платформы** — управляет компаниями, учётными записями и тарифами всего сервиса.

Один и тот же человек может совмещать роли: например, владелец салона обычно ещё и мастер, а мастер
может быть клиентом другого салона. Роли складываются, а не заменяют друг друга.

Один человек может работать в нескольких компаниях. Тогда его расписание, записи и процент комиссии
в каждой компании считаются отдельно и не пересекаются.
