# Расписание, перерывы и свободное время

Статья для мастеров и владельцев компаний. Клиенту она не нужна — он видит только готовый результат:
список свободного времени.

## Где находится расписание

- **Мастер:** «Кабинет» → вкладка **Расписание**. Показывается только ваш собственный график.
- **Владелец:** «Кабинет» → вкладка **Расписание** либо «Мои компании» → **Управление** → вкладка
  **Расписание**. Над календарём — кнопки со всеми мастерами компании, владелец идёт первым.
  Переключаясь между ними, вы правите график каждого.

Если вы работаете больше чем в одной компании, над календарём появятся кнопки с названиями компаний.
**Расписание в каждой компании своё** и не влияет на остальные: можно работать в одном салоне по
будням, в другом по выходным, и на витрине каждой компании будет виден её собственный график.

Расписание компании доступно только тем, кто в ней действительно работает. Посторонний человек не
увидит и не изменит его; сотрудник, которого убрали из компании, доступ к её расписанию теряет.

## Календарь месяца

Календарь показывает один месяц; листается стрелками по бокам от названия месяца. Цвет и подпись
ячейки означают:

- **закрашенная ячейка с интервалом времени** — рабочий день;
- **бледная ячейка с подписью «выходной»** — день отмечен нерабочим;
- **пустая ячейка** — про этот день ничего не задано; для записи он считается нерабочим;
- **точка в правом нижнем углу** — в этом дне есть перерывы;
- **обведённая ячейка** — сегодня.

Прошедшие даты не открываются — задним числом расписание не меняют.

## Настроить один день

Нажмите на дату — откроется окно с этой датой в заголовке.

1. Переключатель **Рабочий день / Выходной**. В положении «Выходной» время и перерывы прячутся:
   день просто закрывается для записи.
2. **Рабочее время** — начало и конец дня (по умолчанию 09:00–18:00).
3. **Перерывы** — кнопка «+ Добавить перерыв» создаёт интервал (по умолчанию 13:00–14:00), его
   границы можно поправить, крестик справа удаляет строку. Перерывов может быть несколько.
4. **Сохранить** — записывает день. **Удалить** (если день уже был заведён) убирает запись о нём, и
   день снова становится «незаданным», то есть нерабочим.

Если сохранить не удалось, причина будет написана прямо в окне.

## Шаблон недели

Заполнять каждый день вручную не нужно. Кнопка **Шаблон** справа от заголовка «Расписание» открывает
недельный шаблон.

1. Для каждого дня недели отметьте галочку **Рабочий** и задайте время. По умолчанию рабочие дни —
   с понедельника по пятницу, 09:00–18:00.
2. **Сохранить шаблон** — запоминает эту неделю за выбранным мастером в выбранной компании. Сам по
   себе шаблон на записи не влияет: это заготовка.
3. **Применить к месяцу** — раскатывает шаблон на текущий календарный месяц.
   **Применить к 3 мес.** — на ближайшие 90 дней от сегодня.

Применение **перезаписывает** дни в выбранном диапазоне: ранее настроенные вручную часы и перерывы в
этих датах заменяются шаблонными. Порядок такой: сначала раскатать шаблон, потом точечно поправить
отдельные дни (отпуск, короткий день).

За один раз можно применить шаблон не больше чем на 366 дней.

Перерывы в шаблоне не задаются — их добавляют уже в конкретных днях.

## Как из расписания получается свободное время

Когда клиент выбирает время, сервис берёт:

рабочие часы мастера в этой компании на эту дату
→ минус перерывы
→ минус время, уже занятое другими записями
→ разбитое по получасовой сетке (начало визита всегда в `:00` или `:30`)
→ минус варианты, в которые услуга не помещается до конца рабочего дня
→ минус уже прошедшее время.

Отсюда несколько следствий, о которых полезно знать:

- **Нет рабочего дня — нет и записи.** Пока день не отмечен рабочим, клиент увидит «Нет доступных
  слотов на этот день».
- **Сетка получасовая.** Услуга длительностью 45 минут будет предлагаться с началом в `:00` и `:30`,
  а «хвост» в 15 минут займёт часть следующего получаса.
- **Занятость общая для всех компаний.** Если мастер работает в двух салонах, запись в первом
  закрывает это время и во втором: человек один и в двух местах одновременно быть не может. А вот
  рабочие часы, наоборот, у каждой компании свои.
- **Ручная запись сотрудника этих правил не соблюдает** — см. ниже.

## Ручная запись вне расписания

Когда сотрудник записывает клиента сам (кнопка «Добавить запись» в разделе «Мои записи»), сетка
свободного времени строится по другим правилам: показываются любые незанятые интервалы суток, без
оглядки на рабочие часы и перерывы. Это сделано намеренно — чтобы принять человека, который пришёл
или позвонил вне графика.

Ограничения, которые действуют всегда, даже для ручной записи: нельзя записать в прошлое, нельзя
наложить запись на уже существующую и нельзя, чтобы визит переходил за полночь.

Тот же принцип действует при переносе записи: сотрудник переносит на любое свободное время.
